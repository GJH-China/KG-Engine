# 版本记录 · Release History

本页记录 KG1 / KG2 系列各版本的训练规模、关键改动与实测成绩。
所有数字来自各版本的评测报告（内部测试集，训练集与测试集严格分离）。

> **KG3 不在本仓库开源。** 它是现役引擎，含新的训练配方，留作底牌。

---

## 快速对比

| 版本 | 发布日期 | 训练样本 | 测试集 | AUC | 检出率 TPR | 误报率 FPR |
|---|---|---|---|---|---|---|
| **KG1** | 2026-09-27 | 2,481 | 1,035 | **0.9973** | 92.54% | **1.20%** |
| **KG2** | 2026-10-12 | 3,157 | 1,319 | 0.9819 | **96.59%** | 5.61% |
| **KG2b** | 2026-10-12 | 5,009 | 2,090 | 0.9866 | 87.56% | 1.58% |
| **KG2c** | 2026-10-12 | 3,577 | 1,494 | 0.9889 | 93.54% | 2.23% |

检出率/误报率均为**阈值 = 0** 的工作点。三个 KG2 版本是同一天的三次不同取舍，
不是简单的"越新越好"——具体见下文。

## KG1

**2026-09-27** · 首版

| | |
|---|---|
| 语料 | 恶意 2,142 / 良性 1,994 |
| 切分 | 训练 2,481 · 校准 620 · 测试 1,035 |
| 通道 | text 1,692 / binary 2,444 |
| **AUC** | **0.9973** |

阈值 0 工作点：

| 指标 | 值 |
|---|---|
| TP / FP / TN / FN | 496 / 6 / 493 / 40 |
| 准确率 | 95.56% |
| 检出率 | 92.54% |
| 误报率 | **1.20%** |
| 精确率 | 98.80% |

**说明**：首版 AUC 最高（0.9973），但这个数字有水分——语料只有 4,136 条，
且良性与恶意样本的来源相对单一。后续版本扩大语料后 AUC 回落到 0.98 区间，
那才是更可信的水平。

> ⚠️ 历史坑：KG1 选定的阈值是 **565.606**。这个值是按 KG1 自己的分数分布选的，
> 直接套到 KG2 上会把召回从 91% 砍到 15%。**换模型必须重标阈值。**

## KG2

**2026-10-12** · 大幅扩充恶意语料

| | |
|---|---|
| 语料 | 恶意 **3,284**（较 KG1 +53%）/ 良性 1,994 |
| 切分 | 训练 3,157 · 校准 790 · 测试 1,319 |
| 通道 | text 1,724 / binary 3,542 |
| **AUC** | 0.9819 |

阈值 0 工作点：

| 指标 | 值 |
|---|---|
| TP / FP / TN / FN | 792 / 28 / 471 / 28 |
| 准确率 | 95.75% |
| 检出率 | **96.59%** |
| 误报率 | 5.61% |

**关键改动**：恶意语料从 2,142 扩到 3,284，检出率从 92.54% 提到 96.59%，
代价是误报率从 1.20% 涨到 5.61%。这一版证明了"扩充恶意样本能显著提召回"，
也暴露了新的瓶颈——**良性样本不够**，误报压不住。

## KG2b

**2026-10-12** · 反向取舍：优先压误报

| | |
|---|---|
| 语料 | 恶意 3,284 / 良性 **5,078**（较 KG2 +155%） |
| 切分 | 训练 5,009 · 校准 1,253 · 测试 2,090 |
| 通道 | text 2,013 / binary 6,339 |
| **AUC** | 0.9866 |

阈值 0 工作点：

| 指标 | 值 |
|---|---|
| TP / FP / TN / FN | 718 / 20 / 1,250 / 102 |
| 准确率 | 94.16% |
| 检出率 | 87.56% |
| 误报率 | **1.58%** |

**关键改动**：良性样本翻倍到 5,078，误报率从 5.61% 压到 1.58%，
但检出率同时掉到 87.56%——**漏报多了 74 条**。

这一版说明了一件事：单纯往一边堆样本只是把工作点沿 ROC 曲线滑动，
不会让曲线本身变好。真正的改进要靠特征和训练方法，不是靠数据量堆。

## KG2c

**2026-10-12** · 当前开源代码对应的版本

| | |
|---|---|
| 语料 | 恶意 3,284 / 良性 **2,694**（取 KG2 与 KG2b 之间） |
| 切分 | 训练 3,577 · 校准 895 · 测试 1,494 |
| 通道 | text 1,724 / binary 4,242 |
| **AUC** | 0.9889 |

阈值 0 工作点：

| 指标 | 值 |
|---|---|
| TP / FP / TN / FN | 767 / 15 / 659 / 53 |
| 准确率 | 95.45% |
| 检出率 | 93.54% |
| 误报率 | **2.23%** |
| 精确率 | 98.08% |

**关键改动**：在 KG2（偏召回）与 KG2b（偏精确）之间取平衡点，误报 2.23% 的同时
保住 93.54% 检出。

🔴 **`MALICIOUS_THRESHOLD = 78.33` 就来自本版本的评测报告**：报告里
`at_fpr_1pct` 档（误报率 ≤1% 的工作点）给出的阈值是 **78.3348**，
取两位小数即 78.33。该档位下 TP 750 / FP 2，检出率 91.5%。

## 外部评测（竞技场）

内部测试集只能反映"在自己的语料上有多好"。公开发布的引擎还会被第三方竞技场
用独立的样本集评测，结果往往更严苛：

| 维度 | KG2c（竞技场） | 说明 |
|---|---|---|
| 检测能力 TPR | 77.4 | 独立样本集，低于内部测试的 93.54% |
| 低误报（100−FPR） | 31.4 | 即 FPR ≈ 68.6% |

**内部 93.54% vs 外部 77.4% 的落差是正常的**，也是必须公开说明的：
自建语料与真实世界的样本分布永远有差距。竞技场那个误报率（68.6%）说明
KG2c 在陌生良性软件上会大量误报——这正是后续版本要解决的核心问题。

## 版本命名约定

- `KGx` —— 主版本，语料或算法有实质变化
- `KGxb` / `KGxc` —— 同一天内的不同取舍（改语料配比、改特征权重），不是修复版
